==============================================================================
   COMO USAR A INTEGRAÇÃO DO ESTAMPARIA MANAGER COM O CORELDRAW 2022
==============================================================================

Você tem 2 formas práticas de vincular e mostrar as quantidades no CorelDRAW:

------------------------------------------------------------------------------
OPÇÃO 1: Script Rápido de 1 Clique (Carimbar Ficha na Arte)
------------------------------------------------------------------------------
1. Abra sua arte no CorelDRAW 2022.
2. Dê dois cliques no arquivo:
   "Carimbar_Ficha_no_CorelDRAW.vbs"
3. O script lerá os pedidos cadastrados no seu aplicativo desktop.
4. Escolha o número do pedido e dê Enter.
5. A Ficha Técnica com a Grade Completa de Quantidades:
   [ P ]  [ M ]  [ G ]  [ GG ]  [ XGG ] e Total de Peças
   será desenhada automaticamente na página ativa do CorelDRAW!

------------------------------------------------------------------------------
OPÇÃO 2: Instalar a Macro Direto Dentro do CorelDRAW (Alt + F11)
------------------------------------------------------------------------------
Para ter o botão diretamente dentro da barra de ferramentas do Corel:

1. Abra o CorelDRAW 2022.
2. Pressione o atalho: Alt + F11 (para abrir o Visual Basic).
3. No menu superior do Visual Basic, clique em:
   Arquivo -> Importar Arquivo... (ou aperte Ctrl + M).
4. Selecione o arquivo:
   "Estamparia_CorelDRAW.bas"
5. Pressione Ctrl + S para salvar o projeto.
6. Pronto! A macro "ConsultarPedidoEstamparia" estará disponível
   no painel de Scripts do CorelDRAW (Janela -> Janelas de Encaixe -> Scripts)
   ou pelo atalho Alt + Shift + F11.

Com isso você pode:
- Ver na tela todas as quantidades por tamanho do pedido;
- Inserir a legenda da grade no arquivo;
- Salvar a arte diretamente na pasta física do cliente no PC.
